# 🚀 ATW WEB FLOW: 4D Web Flow Explorer (Stage 1)

> **Repository**: [https://github.com/ATWISHERE/Webflow](https://github.com/ATWISHERE/Webflow)  
> **Target Audience**: Kids, Students, and Curious Explorers  
> **Tech Stack**: HTML5, Vanilla CSS3, JavaScript (ES6+), Three.js (WebGL), Web Audio API, Web Speech API

---

## 🌟 What is ATW WEB FLOW?
Traditional educational diagrams depict the internet as flat, lifeless 2D arrows. **ATW WEB FLOW adds Space (3D) AND Time (The 4th Dimension)** to reveal the secret life of the web!

Kids enter any website URL, and a tiny courier robot journeys in real-time across floating tech islands—translating domains at the DNS Owl, racing through the Rainbow Fiber Optic Highway, fetching live payloads from the Server Kitchen with an API Waiter Drone, and returning to power on a real interactive website!

---

## 🎮 Core Educational Stations & Metaphors

1. **Station 1: The Client (You!) 💻**
   - **Kid Metaphor**: The curious detective holding a walkie-talkie shouting: *"Hey Internet, show me cute cat videos!"*
   - Interactive 3D laptop with a dynamic canvas screen, glowing trackpad, pulsing Wi-Fi antenna waves, and waving robot buddy.

2. **Station 2: DNS Satellite (The Magic Phonebook Owl) 🔮**
   - **Kid Metaphor**: Humans speak in words like `cat-games.fun`, but computers only speak in numbers called IP addresses (like `142.250.190.46`). The DNS Owl turns website names into secret computer coordinates in 2 milliseconds!
   - 3D Satellite asteroid with rotating solar wings, scanning radar dish, and holographic translation rings.

3. **Station 3: Rainbow Fiber Optic Highway 🌈**
   - **Kid Metaphor**: Glass threads thinner than a strand of hair shooting laser light pulses under oceans and across continents at near the speed of light!
   - Glowing curved 3D spline tube with high-speed streaming photon particles and neon booster rings.

4. **Station 4: Cloud Server Citadel (The Mega Kitchen) ☁️**
   - **Kid Metaphor**: A super-computer that never sleeps! When your packet arrives, the server is like a master chef: it opens its recipe vault, cooks up your HTML skeleton, paints the CSS style, packages them in a neat lunchbox, and sends it home!
   - 3D floating cloud fortress with skyscrapers, blinking LED arrays, glowing plasma core, and spinning cooling fans.

5. **Station 5: API Messenger Drone (The Digital Waiter) 🤖**
   - **Kid Metaphor**: At a restaurant, you don't cook in the kitchen—you tell the WAITER! The waiter runs to the chef and brings back just your food. An API is the waiter—it fetches live weather, game high scores, or chat messages without reloading the whole universe!
   - Animated hovering quadcopter drone that swoops down dynamically to hand over the live API cargo box to the courier robot!

6. **Station 6: Build-A-Page Lab (HTML, CSS & JavaScript) 🧪**
   - **Kid Metaphor**: Every webpage is a living superhero robot!
     - 🦴 **HTML**: The Bone Skeleton (wireframe scaffolding, text, headings, buttons)
     - 🎨 **CSS**: The Clothes & Painted Armor (neon colors, glowing capes, fonts, curves)
     - ⚡ **JavaScript**: The Brain & Batteries (makes the robot dance, jump, react to clicks, and shoot confetti!)
   - Live switches allow kids to toggle CSS and JavaScript on and off to see what happens to the page in real-time.

7. **Station 7: Webpage vs Website (The Magic Book) 📖**
   - **Kid Metaphor**: A Webpage is ONE SINGLE PAGE in a comic book. A Website is the ENTIRE COMIC BOOK bound together by hyperlinks!

## 🕹️ Interactive Features

- **🎥 Free-Will Zoom Follow Camera**: Click `🎥 Follow: ON (Free Zoom)` to lock camera tracking onto Robot Byte, while retaining complete free will to zoom in as close as 6 units or zoom out up to 180 units away (using the mouse wheel) to view the API Drone and the entire world!
- **⏱️ 4D Temporal Time Scrubber**: Scrub backwards and forwards in milliseconds to follow every stage of a packet's flight, or press Spacebar to play/pause.
- **⚡ Speed Selector**: Choose between 🐢 **Slow** (0.25x), 🚶 **Normal** (0.6x), or 🏃 **Fast** (1.2x) playback.
- **🐱 Live Working Website (Cat Games Live)**: Once the robot returns, test the live JavaScript toys (throw yarn, feed fish, shine laser, change hats) and dynamic API stats (players online, weather).
- **🔊 100% Procedural Web Audio Synth**: Synthesized robot pops, cat meows, drone chimes, and fanfare chords with zero external audio dependencies.
- **🗣️ Robot Voice Narration**: Friendly robotic voice that reads out station analogies and trivia.
- **📱 Multi-Device Wi-Fi Sharing**: Connect mobile phones and tablets on the same Wi-Fi using the built-in `📱 Mobile Link` feature.

## 🏃 How to Run

### Method 1: Double-Click `start.bat` (Recommended!)
Just double-click **`start.bat`** in the project folder!
- Automatically frees port `5173` if occupied.
- Detects your computer's local Wi-Fi IP address.
- Binds to `0.0.0.0` so you can open it on your PC AND mobile phone simultaneously.
- Opens your default browser automatically to `http://localhost:5173/`.

### Method 2: Manual Terminal Command
```bash
# Using Python
python -m http.server 5173 --bind 0.0.0.0

# Or using Node.js
npx -y serve -p 5173 -l 0.0.0.0 .
```

- **PC Browser**: [http://localhost:5173/](http://localhost:5173/)
- **Mobile Browser**: `http://<your-lan-ip>:5173/` *(e.g. `http://192.168.1.2:5173/`)*

## ⌨️ Keyboard Controls
- `Spacebar`: Play / Pause 4D Time flow
- `Left / Right Arrows`: Scrub time backwards and forwards
- `Escape`: Close all open dialogs and modals
- `Mouse Wheel`: Zoom in / out freely in Follow Mode
- `Mouse Left-Click Drag`: Orbit and inspect the 3D scene from any angle
